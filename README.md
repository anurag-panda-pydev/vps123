# 🚀 Google IDX VM Setup Guide

---

## 🖥️ 1. Installing VM in Google IDX

**Google IDX:**
[https://idx.google.com/](https://idx.google.com/)

1. Sign up on Google IDX.
2. Create a new workspace using this repository (**Do NOT change the repo name**):

**Repository URL:** https://github.com/anurag-panda-pydev/vps123

### ▶️ VM Setup Command

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/anurag-panda-pydev/vps123/main/vps.sh)
```
or (preffered)
```bash
chmod +x vps.sh && ./vps.sh
```
